# Financial Advisor Bot — CM3070 Final Project (Aly Thabet)

Research prototype for the CM3020 Artificial Intelligence template, Project Idea 2.
Everything that runs is in [`code/`](code/README.md): the advisor package, the
Streamlit interface, the evaluation and the offline test suite.

- [`code/README.md`](code/README.md) — how to run it and what the results are
- [`docs/preregistration.md`](docs/preregistration.md) — hypotheses fixed before the held-out run
- [`docs/adrs/`](docs/adrs/) — the main design decisions
- [`docs/user-study/`](docs/user-study/) — the script that summarises the user study (H4)
- [`demo/`](demo/) — slides used in the demo video

Recommendations only: no trading, no money, no broker connection.
