# ADR 0002 — Novelty angle: calibrated confidence + counterfactual explanations

**Status:** Accepted
**Date:** 2026-05-14
**Author:** Aly Thabet
**Depends on:** ADR 0001

---

## Context

A first-class project needs a genuine novelty contribution, not just "applied technique X to problem Y." Six candidate novelty threads were considered during planning (see *Alternatives considered*). The 31-paper literature review (Chapter 2 of the report) identifies one open gap that none of the existing peer-reviewed work covers.

## Decision

The novelty angle is:

**A calibrated, counterfactual LLM stock-recommendation system, evaluated by walk-forward backtest on US equities.**

Specifically, the bot will produce four outputs per trading day per ticker:
1. A recommendation (BUY / HOLD / SELL)
2. A confidence score, elicited verbally from the LLM (Tian et al. 2023, EMNLP) and post-hoc calibrated via temperature scaling (Guo et al. 2017, ICML).
3. A plain-English reason.
4. A counterfactual — *"I would change my mind if X happens"* — generated by a DiCE-style algorithm (Mothilal et al. 2020, FAccT), grounded in the GDPR right-to-explanation framing of Wachter et al. (2018, Harvard JOLT).

The bot's confidence will be evaluated using Expected Calibration Error (Naeini et al. 2015, AAAI). The user study (3–5 non-technical users) will assess whether the counterfactual increases trust and sanity-check behaviour vs the recommendation-only condition.

## Alternatives considered (the six candidate threads)

1. **Multi-perspective LLM ensemble** (bull/bear/risk-manager debate) — rejected: FinCon already occupies this space at NeurIPS 2024; difficult to differentiate.
2. **Confidence-calibrated explanations** — selected as primary, fused with counterfactuals (see below).
3. **Counterfactual risk reasoning** — selected as a fused second pillar — strengthens the contribution by occupying a column neighbouring works do not touch.
4. **Walk-forward prompt evolution** — rejected: under-resourced for a 24-week solo project, weak evaluation handle.
5. **HCI angle** — partially preserved via the mandatory non-technical user study. Not the primary thread.
6. **Open-vs-closed LLM comparison** — rejected: comparative ML benchmarks rarely yield publishable contributions without large compute budgets.

## How the angle is defended in the proposal video (May 18)

Slide 5 of the project-proposal deck features an **"Identified Gap · Our Contribution"** callout that states verbatim:

> *No prior peer-reviewed work combines LLM stock recommendations + calibrated confidence + counterfactual explanations, walk-forward backtested on US equities.*

## How the angle is evaluated

The evaluation chapter will report:
- **Profitability** vs four baselines (buy-and-hold, random allocation, 12-1 momentum, Markowitz mean-variance), with Deflated Sharpe (Bailey & López de Prado 2014).
- **Calibration** via Expected Calibration Error on the bot's confidence outputs.
- **Ablation** — bot with vs without the LLM layer, isolating the LLM's contribution.
- **User study** — 3–5 non-technical users compare a counterfactual-on vs counterfactual-off condition on explanation clarity (Likert) and behavioural sanity-checking.

This four-pronged evaluation maps directly onto the four marker rubric questions for the *final report*: working system + significant testing in all components + detailed evaluation + interesting & advanced algorithm.

## Risks to this angle

| Risk | Mitigation |
|---|---|
| A 2025 paper appears in the next 6 months that closes this gap | Daily ArXiv watch; pivot to a sub-thread (e.g. emphasise the user-study HCI angle) if pre-empted |
| Llama 3.1's verbal confidence proves uncalibratable on this domain | Fall back to logit-based calibration (less novel but still functional) |
| User study (n=3–5) is statistically underpowered for the counterfactual claim | Report qualitatively as required by the brief; statistical claims confined to backtest evaluation |

## Pre-registration

For methodological rigour, the evaluation hypotheses will be pre-registered in `docs/preregistration.md` before any final backtest is run on the held-out 2025–2026 test set. The pre-registration commits the following hypotheses:

- H1 (profitability): The bot's Deflated Sharpe ratio exceeds buy-and-hold S&P at p < 0.05 over the held-out test set.
- H2 (calibration): The bot's Expected Calibration Error is lower than that of the LLM's raw verbal confidence (pre-temperature-scaling).
- H3 (ablation): Removing the LLM layer degrades risk-adjusted return by ≥ 20% on the held-out test set.
- H4 (user study): Counterfactual-on condition produces higher Likert-scale "I understand why" ratings than counterfactual-off, n=3–5 paired.

H1–H4 will be locked in writing before any final-evaluation backtest is executed.

## Outcome (recorded 23 September 2026, after the held-out evaluation)

The angle held up, though not in the way first expected. Calibration was implemented and evaluated as planned, but on this task the models' verbal confidence turned out to carry no information within BUY/SELL calls, so temperature scaling could only flatten it (H2 not supported). The interface now shows each advisor's measured track record beside its stated confidence. The counterfactual half became the strongest result: the verified search reproduced its flips on fresh calls and exposed the rule Llama actually follows (buy when RSI is below about 40), while the models' own "what would change my mind" sentences held up only 18/40 (Llama) and 39/40 (Qwen) times. See report Chapter 5.
