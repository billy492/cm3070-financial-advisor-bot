## Context

CM3070 requires a template-bound project. Section 4.2 explicitly invites the student to choose:
- the financial market (stocks, FX, crypto, classic cars)
- the AI/ML technique (RL, evolutionary, neural networks, LLM-based agents)
- the interaction surface (the brief mandates a non-technical user web interface)
- the prototype-to-final scope

Locking these choices early protects against late-project re-scoping, which the lecturer videos (Tara, Andrea) explicitly warn against.

## Decisions

### D1 — Market: US stocks

**Decision.** The bot will operate on US equities, sourced from `yfinance`.

**Rationale.**
- The CM3070 brief explicitly recommends `yfinance` for stock data.
- Peer-reviewed literature depth is substantially higher for equities than for crypto (Markowitz 1952, Jegadeesh & Titman 1993, Fischer & Krauss 2018, Sezer et al. 2020, Olorunnimbe & Viktor 2023 — all directly applicable).
- Clean separation from the author's APOLLO project (crypto on Binance testnet), eliminating academic-integrity exposure.
- Standard baselines (S&P 500 buy-and-hold, 12-1 momentum, Markowitz mean-variance) are well-defined for equities.

**Alternatives considered.**
- Crypto: rejected — overlap with APOLLO creates integrity questions for the marker.
- FX: rejected — thinner academic literature on LLM agents for FX.
- Classic cars: rejected — no usable data feed.

### D2 — Project start date: 2026-05-14

**Decision.** Project Week 1 is the week of Mon 11 May 2026 (treating 14 May as Week 1, Day 4).

**Rationale.**
- The Coursera-platform Project Proposal video deadline is Sun 18 May 2026, 4:00 PM EEST. Locking Week 1 to the week containing that deadline keeps all downstream deliverables on the official 24-week calendar.
- Preliminary Report (Week 10, 10%) lands ~27 July 2026.

### D3 — Algorithm class: LLM-augmented multi-signal advisor

**Decision.** A hybrid pipeline — classical technical indicators feed a local LLM (Llama 3.1 via Ollama) which emits a recommendation, a verbal confidence score, a plain-English explanation, and a counterfactual. Confidence is post-hoc calibrated via temperature scaling. Counterfactuals are generated by DiCE.

**Rationale.**
- Lands in the 2024–2025 LLM-agents-in-finance research frontier (FinCon, MarginTrader, TradingAgents, FinAgent, FinBen).
- Closes the marker rubric's "interesting and advanced algorithm with significant effort" criterion required for the 1st-class band.
- Differentiates from APOLLO's strategy-routing architecture — no code reuse, only conceptual lineage.

**Alternatives considered.**
- Pure RL (e.g. DQN on price features): rejected — well-trodden, less defensible novelty contribution.
- Evolutionary strategy: rejected — slower iteration cycle for a 24-week thesis.
- Multi-agent LLM debate (FinCon-style): rejected — over-complexity for a non-technical UX target.

### D4 — Non-technical user interface: Streamlit → Flask

**Decision.** Streamlit for the prototype (Weeks 8–10). Flask for the final web UI (Weeks 18–22).

**Rationale.**
- Streamlit gets a working interactive UI in hours, enabling early user-study iteration.
- Flask gives a more academically-defensible final-report architecture.
- Both run locally on the marker's laptop, satisfying the brief's "should be able to interact with the advisor bot" requirement without deployment costs.

### D5 — Backtest universe + window

**Decision.**
- Universe: ~50 US tickers across sectors (S&P 500 + NASDAQ-100 subset).
- Training: 2020-01-01 → 2025-01-01 (~5 years).
- Hold-out test set: 2025-01-01 → 2026-05-14 — never seen during model development.
- Validation: walk-forward only (Bergmeir et al. 2018; López de Prado 2018).

**Rationale.**
- 50 tickers is large enough to demonstrate portfolio management, small enough to backtest cheaply.
- A held-out final-year test set is mandatory for a 1st-class evaluation chapter.
- Walk-forward CV is the correct discipline for time-series — random shuffling is the most common amateur mistake in this domain.

### D6 — Scope hard limits

**Decision.** Historical data + paper simulation only. No live trading. No real money. No broker API keys. No automated execution.

**Rationale.** Required by the project's scope lock (research and demonstration only) and its research framing.

### D7 — Target publication venue (stretch)

**Decision.** Defer to post-thesis. Default target: ICAIF 2026 (ACM International Conference on AI in Finance), with a ~6-week post-submission paper-draft window. Alternative: NeurIPS Workshop on AI in Finance or ACL FinNLP, depending on which novelty thread strengthens during development.

**Rationale.** Premature publication-venue commitment biases the methodology. We earn the right to choose the venue after the evaluation chapter is written and the contribution is empirically defensible.
